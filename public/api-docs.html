Economic Bomb API
A fully public REST API for Economic Bomb data. No key required. Build stat trackers, server dashboards, leaderboard bots, or anything else.
Base URL
economicbomb.nrglearning.xyz/api/v1
Version
v1.1.0
Auth
None
Rate Limit
30 / min
Rate Limiting
All endpoints are limited to 30 requests per minute per IP address. Exceeding the limit returns a 429 response. Every response includes rate limit headers.

X-RateLimit-Limit - max requests per window
X-RateLimit-Remaining - requests left this window
X-RateLimit-Reset - Unix ms timestamp when the window resets
Response Format
Success
{
  "ok": true,
  "data": { ... your data here },
  "timestamp": "2026-06-15T00:00:00.000Z"
}
Error
{
  "ok": false,
  "error": "Description of what went wrong.",
  "timestamp": "2026-06-15T00:00:00.000Z"
}

JavaScript
// Player stats (global - no guildId needed)
const res = await fetch('/api/v1/player/123456789012345678');
const { data } = await res.json();
console.log(data.netWorth);

// Global leaderboard top 10
const lb = await fetch('/api/v1/leaderboard/global?limit=10');
const { data: board } = await lb.json();
board.players.forEach(p => console.log(p.rank, p.userId, p.netWorth));

// Network stats
const stats = await fetch('/api/v1/stats');
const { data: s } = await stats.json();
console.log(s.totalPlayers, s.totalServers);
Python
import requests

BASE = "http://economicbomb.nrglearning.xyz/api/v1"

# Network stats
r = requests.get(f"{BASE}/stats")
data = r.json()["data"]
print(data["totalPlayers"])

# Player stats (global)
r = requests.get(f"{BASE}/player/123456789012345678")
player = r.json()["data"]
print(player["netWorth"])

# Global leaderboard
r = requests.get(f"{BASE}/leaderboard/global", params={
    "sort": "networth",
    "limit": 10
})
players = r.json()["data"]["players"]
